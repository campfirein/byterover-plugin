# Grove plugin (v0.4.1)

Generated by `@byterover/grove-plugin`. Do not edit these files by hand: edit the source in
`apps/plugin` and rebuild.

Answer company questions from your Grove Company Brain: accepted context about the company, product, team and decisions, and propose new facts for review.

## Install

Claude Code:

```bash
claude plugin marketplace add campfirein/grove-plugin
```

```bash
claude plugin install grove@byterover
```

Cowork: open Customize, then Plugins, then Add marketplace, and enter
`campfirein/grove-plugin`. Click Save plugin on the card to finish.

Other agents: point your client's plugin setup at this directory.

Restart the session, or run `/reload-plugins`, before the skill loads.

## Requirements

Grove Desktop, installed at `/Applications/Grove.app` and signed in. The plugin reads the
Brain selected there. macOS stable build for now, and `brain__query` only: propose new facts
from Grove Desktop.
