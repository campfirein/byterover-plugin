# ByteRover plugin (v0.8.1)

Generated by `@byterover/byterover-plugin`. Do not edit these files by hand: edit the source in
`apps/plugin` and rebuild.

Answer company questions from your ByteRover Company Brain: accepted context about the company, product, team and decisions, and propose new facts for review.

## Install

Claude Code:

```bash
claude plugin marketplace add campfirein/byterover-plugin
```

```bash
claude plugin install byterover@byterover
```

Cowork: open Customize, then Plugins, then Add marketplace, and enter
`campfirein/byterover-plugin`. Click Save plugin on the card to finish.

Other agents: point your client's plugin setup at this directory.

Restart the session, or run `/reload-plugins`, before the skill loads.

## Requirements

A ByteRover account. The plugin connects to `https://dev-mcp.byterover.dev/mcp` and opens a browser for
sign-in and consent on first use. Grove Desktop is not required, and neither is a particular
operating system: there is nothing to launch locally.

The remote MCP surface is read-only while its final tool contract is being defined.
